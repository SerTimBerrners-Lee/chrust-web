# Chrust

Лендинг приложения с разделами «Рост», «Курсы», «Игры» и «Библия».

## Разработка

```sh
bun run build
bun run dev
```

Адрес предпросмотра: `http://127.0.0.1:4173/`. Внешние зависимости не нужны.
Статическая папка `dist` хранится в Git. После правок исходников выполните сборку.

Изменения сначала согласуются локально. Push и публикация допускаются только
после отдельного подтверждения пользователя. Текущий порядок описан в `AGENTS.md`.

## Страницы и ссылки

- `/`: автоматический выбор языка, английский текст при отключённом JavaScript.
- `/ru/`: русский лендинг для тестовой аудитории.
- `/en/`: английский лендинг.
- `/download/`: автоматический выбор языка страницы скачивания.
- `/ru/download/`, `/en/download/`: выбор платформы на указанном языке.
- `/ru/bible-games/`, `/en/bible-games/`: библейские игры и викторина с ответами.
- `/ru/bible-word-search/`, `/en/bible-word-search/`: пример филворда и правила.
- `/ru/bible-reading-plan/`, `/en/bible-reading-plan/`: полный годовой список глав.
- `/ru/bible-study-for-beginners/`, `/en/bible-study-for-beginners/`: первое занятие по изучению Библии.
- Новые индексируемые страницы RU/EN: `spiritual-growth`, `old-testament-study`,
  `new-testament-study`, `bible-lessons`, `bible-crossword`, `bible-quiz`,
  `bible-matching-pairs`, `build-a-bible-verse`, `guess-bible-verse`.
- Всего 13 материалов на язык. Все доступны в футере, сгруппированном по
  четырём направлениям. Текущая страница не скрывается из каталога.
- `site/links.json`: основной домен сайта, адреса магазинов, веб-приложения и социальных сетей.

Основной адрес сайта: `https://chrust.org`. Канонические ссылки страниц и
ссылки языковых версий используют этот домен. Внутренняя навигация остаётся
относительной и работает в локальном предпросмотре.
На общих адресах `/` и `/download/` сначала учитывается сохранённый ручной
выбор, затем первый поддерживаемый язык из списка языков браузера.
Поддерживаются русский и английский; запасной язык английский.
Прямые адреса `/ru/` и `/en/`, включая скачивание, никогда автоматически
не меняют язык. Это сохраняет доступность обеих версий для людей и поиска.
Язык выбирается локально, без определения страны по IP и передачи данных.
Ошибка доступа к хранилищу браузера не мешает работе переключателя.
Автоматический переход сохраняет параметры и якорь входящей ссылки,
ручное переключение открывает страницу сверху. `x-default` ведёт на общий
адрес выбора языка, а у материалов на английскую версию того же материала.
Каждая языковая версия имеет собственный canonical.
Подсветка наведения работает только
для устройств с мышью; после касания на телефоне пункт меню не остаётся
подсвеченным. Клавиатурный фокус сохраняет видимую рамку.
Кнопки «Начать» и входа в приложение ведут на `https://app.chrust.org`.
Лендинг размещается на сервере `212.119.42.46`.
Само приложение на `app.chrust.org` этой настройкой не разворачивается.

Кнопка Telegram открывает канал `https://t.me/chrustapp` в новой вкладке.
Instagram ведёт на `https://www.instagram.com/chrust.app/`,
Threads на `https://www.threads.com/@chrust.app`,
YouTube на `https://www.youtube.com/@ChrustApp`.
Адреса магазинов пока остаются заглушками.
Кнопки соцсетей и магазинов отображают только иконки,
без подписей и слова «Скоро». Доступные имена и подсказки сохранены. Значение
`null` в конфигурации означает заглушку. После добавления HTTPS-адреса и сборки
кнопка становится обычной внешней ссылкой.
«Скачать», кнопка в шапке и скриншоты ведут на страницу скачивания.

## Структура

- `scripts/build.ts`: генерация страниц, локализация, иконки и ссылки.
- `site/content.ts`: русский и английский текст и состав коллажей.
- `site/styles.css`: адаптивное оформление.
- `site/interactions.js`: движение карточек и слабый ветер.
- `site/language.ts`: выбор языка и запоминание ручного переключения.
- `site/guides.ts`, `site/guide-view.ts`: материалы и их общая разметка.
- `site/guide-expansion.ts`: дополнительные страницы «Роста», курсов и игр.
- `site/guide-navigation.ts`: четыре группы футера и связанные материалы.
- `site/reading-plan.ts`: 1189 глав по дням обычного или високосного года.
- `site/seo.ts`, `site/seo.json`: метаданные, карта сайта, режим индексации и год плана.
- `site/search-verification.json`: публичные метатеги подтверждения владельца в Google и Яндексе. Не удалять после подтверждения; они не собирают данные посетителей.
- `docs/seo-plan.md`: согласованный план продвижения, измерения и следующие шаги.
- `dist/assets/screens`: исходные демонстрационные скриншоты приложения.
- `screenshot-sources.json`: происхождение скриншотов.
- `asset-sources.json`: происхождение иллюстраций и других ресурсов.
- `site/hero-oak-prompt.txt`: промпт дуба.
- `site/rays-transparent-prompt.txt`: промпт прозрачной версии лучей.
- `.openai/hosting.json`: идентификатор Sites и каталог статических файлов.

## Оформление и движение

Элементы шапки имеют общую высоту 48 px. Основные кнопки первого экрана
уменьшены до 60 px на компьютере и 56 px на телефоне. Соцсети и платформы
используют общую компактную кнопку шапки с одной иконкой.

Шапка использует оформление из `IllustratedScreenStyle` приложения Chrust:
тёплую полупрозрачную поверхность, размытие 16 px, тень текста 25% с отступом
1 px и размытием 4 px, светлые кнопки `#f5e6d4` и тёмный текст `#30251d`.
Логотип с прозрачным фоном создан встроенным ImageGen на основе исходных лучей.

Карточки сохраняют прежнюю раскладку и перекрытие примерно на треть.
У семи скриншотов с нижней навигацией видимая область ограничена первыми
1560 из 1688 пикселей. Исходные файлы сохранены. Кнопки уроков и игр
на остальных скриншотах остаются видимыми.
Для коллажа курсов сняты три новых экрана из уже запущенного приложения:
карта, иллюстрированное начало урока «Сотворение мира» и выбор Завета.
У карты и раздела «Учить» нижняя навигация исключена при съёмке. Экран
начала урока изначально полноэкранный. Метаданные есть в `screenshot-sources.json`.
Наведение смещает карточку не более чем на несколько пикселей и слегка
наклоняет её, сохраняя исходный порядок наложения.

Ветер рисуется локально через WebGL: небольшое смещение применяется только
к зелёной листве и траве, по маске цвета и расположения. Цикл ограничен
30 кадрами в секунду, при уходе из видимой области останавливается.
Есть кнопка паузы и поддержка `prefers-reduced-motion`. При недоступном WebGL
или потере контекста остаётся обычное изображение.

## Содержание

Нижний блок теперь посвящён скачиванию и использует сгенерированный дуб.
Оформлены App Store, Google Play, RuStore и вход в веб-приложение.
Вход в браузере показан текстовой кнопкой «В приложение».
Круглые кнопки центрируют SVG без внутренних отступов и базовой линии текста.
Для текстовых кнопок явно заданы симметричные отступы и высота строки.
В «О Chrust» описаны цель, ежедневная практика и образ дерева, которому
нужна забота. Telegram, Instagram, Threads и YouTube ведут на страницы Chrust.

В разделе «О Chrust» семь готовых иллюстраций уроков заполняют исходную
асимметричную сетку со скруглениями. Размеры плиток, фон страницы и тексты
сохранены. WebP не перекодируются; их контрольные суммы проверяются при сборке.
Изображения хранятся отдельно от Git в Git LFS. Перед локальной сборкой
установите Git LFS и выполните `git lfs pull`; GitHub Actions загружает их
автоматически. Нижние углы первого экрана скруглены. Скриншоты приложения используют демонстрационные
данные и русский интерфейс в обеих версиях сайта. Тексты сайта переведены.
Аналитика и внешние исполняемые скрипты отсутствуют.

## Поисковое продвижение

Продвигается `chrust.org`, а не адрес приложения. Главные страницы RU/EN и
26 полезных материалов доступны для индексации. Они работают без входа
и JavaScript. Годовой план содержит все 1189 глав по одному разу; год задаётся
в `site/seo.json`. При смене года обновите настройку и пересоберите сайт,
не создавая новый адрес страницы.

Каждый материал использует тематический коллаж из исходных скриншотов
главной: игры и филворд показывают игровые экраны, план чтения объединяет
«Рост» и Библию, вводное изучение показывает курс. Состав коллажей задан
в `guidePreviewScreens` в `site/guides.ts`. Общий блок «Chrust всегда рядом»
повторяется внизу каждого материала. Футер всех страниц содержит ссылки
«Скачать», «В приложение» и общие кнопки Telegram, Instagram, Threads,
YouTube. Адреса и заглушки магазинов остаются общими.

В расширении также используются отдельные экраны и оригинальные
иллюстрации игр. Новые иллюстрации скопированы без изменений из
`apps/chrust_app/assets/images/games/production` репозитория Chrust.
Происхождение и контрольные суммы сохранены в `screenshot-sources.json`.
Они не обозначаются как скриншоты игрового поля.

Пустые страницы скачивания сохраняют `noindex, follow`. `sitemap.xml`
содержит 28 канонических страниц: две языковые главные и все 26 материалов.
Ссылка на карту есть в `robots.txt`. Состав материалов задаётся в `guideSlugs`,
отдельного запрета для расширения больше нет. Собираются 32 страницы;
публикация и открытие индексации согласованы пользователем 21 октября 2026 года.
Корневой адрес остаётся языковым входом с английским canonical.
Общее выключение индексации доступно через `indexingEnabled` в `site/seo.json`.
Это аварийная настройка, а не зависимость от доступности приложения.
Карта сайта при этом остаётся доступной, но страницы получают `noindex`.

[План продвижения](docs/seo-plan.md) опирается на сохранённые измерения Google
и Яндекса в `research/`. Остальные языки отложены. Владение сайтом подтверждено
в Google Search Console и Яндекс Вебмастере. Google принял карту сайта;
ручная отправка в Яндекс ожидает снятия режима «Только для чтения» в сервисе.
Статусы и следующие действия записаны в плане. Счётчики посетителей не подключены.

## Автоматическая публикация

Изменения в `main` запускают `.github/workflows/deploy.yml`: сборку всех 32
страниц, тесты сайта и приёмника публикаций, затем доставку `dist` на сервер.
Одновременно выполняется только одна выкладка. Другие ветки не публикуются.
Действия GitHub закреплены по коммитам, Bun по версии 1.3.14.

GitHub использует секрет `CHRUST_DEPLOY_KEY` и отдельного пользователя
`chrust-web-deploy`, без root-доступа, терминала и перенаправления портов.
Ключ разрешает только `/usr/local/libexec/chrust-web-deploy`.
Ключ сервера закреплён в `ops/known_hosts`.

Файлы поступают в отдельный каталог `/var/www/chrust.org/releases`.
Приёмник `ops/deploy.py` отклоняет неполный архив, ссылки, скрытые файлы,
пути вне каталога и слишком большой набор. После проверки переключает
`current` на новую версию одной операцией. `previous` указывает на предыдущую
версию; старые каталоги автоматически не удаляются. Служебный `version.json`
позволяет проверить, какой коммит реально обслуживается.
Если проверка после публикации не прошла, задание GitHub отмечается ошибкой;
автоматического отката после этой внешней проверки нет.
Повторная отправка того же коммита выполняется через повторный запуск workflow.

Первичная настройка выполнялась отдельно от остальных сайтов сервера.
Шаблон HTTP-конфигурации: `ops/chrust.org.nginx.conf`.
Конфигурация для использования после выпуска сертификата:
`ops/chrust.org.https.nginx.conf`.
`ops/setup-server.sh` предназначен только для первого подключения: он не
перезаписывает существующий серверный блок Chrust.

20 октября 2026 года подключён HTTPS для `chrust.org` и `www.chrust.org`.
Оба имени указывают на `212.119.42.46`; HTTP перенаправляется на
`https://chrust.org` с сохранением пути. На сервере установлен шаблон
`ops/chrust.org.https.nginx.conf`. Предыдущая конфигурация сохранена рядом:
`/etc/nginx/sites-available/chrust.org.http-20261020-19232ed.bak`.
Certbot продлевает сертификат через `/var/www/chrust.org/acme`;
активен `certbot.timer`, после продления выполняется проверка и перезагрузка
nginx. Не задавать AAAA-запись без настроенного IPv6.
Проверка `certbot renew --cert-name chrust.org --dry-run --non-interactive`
успешно прошла 20 октября 2026 года.
Состояние DNS и HTTPS проверяется отдельно от доставки файлов.
Для отката администратор может атомарно направить `current` на каталог,
который указан в `previous`, и проверить `version.json`.

Локальные проверки:

```sh
bun run build
bun run test
python3 -m unittest discover -s ops -p 'test_*.py' -v
```

Тесты приёмника используют временные каталоги, не рабочую папку сервера.
